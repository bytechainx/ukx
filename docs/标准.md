# ukx 标准文档

**crate**：`ukx` v0.1.0 · **source_id**：`uk_cb` · **角色**：英国央行数据源事实层 ·
**状态**：`production_decision = NO-GO`（无采集授权，non-package-stable）

权威输入：`specs/adapter/uk_cb.md`（采集范围权威）。
本文只登记本库**已落地**的能力标准与其边界；未落地者逐条写明。

## 1. 源事实范围

- 本源覆盖清单 §1.1 的 S01–S11 规划源、§1.2 的 6 个关键 IADB 码、
  §1.3 的曲线边界与 §1.4 的规划调度。
- 本库**只做**类型化、离线解析、校验与路由 / 授权判定；**不做**采集、存储与再分发。
- 清单未固定的内容（端点、Series 全集、UA、限流、许可、统计口径）
  一律**不得**在本库出现。
- 授权现状为 `unknown`（无 Owner 签核文件；Series / UA / 许可 UNKNOWN），
  故一切判定按 fail-closed 进行。

## 2. 源登记 S01–S11

- `SOURCE_PLANS` 逐条落 S01–S11 的 **标识 + 名称 + 清单「形式」逐字文本 +
  清单点名的格式 + 清单「频率」逐字文本**。
- 「形式」列给的是节奏而非格式者（S02 / S06 / S08 / S09），`formats` 为**空**：
  离线解析返回 `NotApplicable`，**不猜**格式。
- 清单点名两种形式者（S01 `CSV/XML`、S03 `CSV/Excel`、S07 `ZIP`+`xlsx`）
  按清单原样登记为数组。
- 格式名与源标识都是**枚举**，不是自由文本；`as_str` 给出清单使用的标识。

## 3. 关键 IADB 码与不得扩集

- `UkCbIadbCode` 恰有清单 §1.2 的 **6 个**关键码，`IADB_KEY_CODES` 与清单逐行对应。
- `iadb_code` / `UkCbIadbCode::from_code` 是**严格**选择入口：大小写敏感、不做近义推断，
  不在 6 个种子内者返回 `SemanticallyRejected`。
- 清单把该表题为「规划**白名单种子**」，全集未钉死 ⇒ 本层**不得**自行扩集，
  也不得用近义码互相顶替。
- 观测里的序列标识（`UkCbSeriesId`）**原样保留**源侧文本；需要判定是否为关键码时
  走 `UkCbSeriesId::iadb_code`，命中才返回 `Some`。

## 4. 曲线路由边界

- S07 收益率曲线（nominal / real / OIS）MUST 派往 `yield_curve` 槽位
  （#11 `boe_iadb` / #12 `uk_dmo`），**不得**直写观测。
- `guard_curve` 是解析前的第一道判定：曲线源返回 `RoutedElsewhere`，
  **优先于**格式未实现判定（即先报路由，再报 NotApplicable）。
- `CURVE_ROUTE` 只登记槽位与清单点名的 provider；本层**不**代理该槽位的任何职责。

## 5. 规划调度口径

- `PLANNED_SCHEDULE` 落清单 §1.4 的 8 条窗口：SONIA 08:05 / 08:35、
  IADB 日度 16:30、Bank Return 周四 15:05、APF 操作日 14:35、曲线 18:00、
  月度日历驱动（无固定时刻）、02:00 补采校验。
- **调度是规划语义，不是访问合同**：不表达访问时点、抓取窗口、限流配额或 SLA。
  本层无网络、无授权，任何时刻都不得被当作可执行参数。
- 清单只写「日历驱动」者登记为 `None`，而非猜测出来的时刻。

## 6. 离线解析形态（CSV / JSON）

- 解析入口为 `parse_uk_cb_observations(source, input)`：参数是**源标识 + 字符串**，
  不接受 URL、HTTP 客户端、认证信息、环境变量或代理配置。
- 本层只实现**两种**形态：CSV 与 JSON。其余格式（xlsx / ZIP / XML / Excel）
  与「形式」列未点名格式的源一律返回 `NotApplicable`，**不得假装已支持**。
- **CSV 子集**（本层声明的离线交换形态，不是 BoE 文件布局）：
  前导注释行以 `#` 开头；表头逐字为
  `series,period,value,unit,frequency,revision`；数据行恰 6 列；
  字段不得含引号（含引号即拒绝，以防误解析）；允许一次 UTF-8 BOM。
- **JSON 形态**：根对象 `_synthetic` + `_note` + `observations`，
  每项字段为 `series` / `period` / `value` / `unit` / `frequency` / `revision`。
- 期间形态为 `YYYY-MM-DD` / `YYYY-MM` / `YYYY-Qn` / `YYYY` / `event:YYYY-MM-DD`。

## 7. 原子失败与重复身份

- **未知字段原子失败**：CSV 表头多列、少列、改名、换序一律整体失败；
  JSON 根对象与观测项都拒绝未知字段。**不做**静默忽略。
- **缺必需字段失败**：缺表头、缺列、CSV 行数不符、JSON 缺 `observations` 等整体失败。
- **重复身份**：同一「序列 + 业务期间」在样本内出现两次即整体失败；
  本层选择**拒绝**而不是去重。
- **只接受显式标注的合成样本**：`_synthetic` 必须为 `true` 且 `_note` 非空；
  未标注或自称真实（`_synthetic: false`）者一律语义拒绝。
- 错误消息只给形态与位置（行列 / 第几行），**不回显**原始正文、取值片段或凭据。

## 8. 缺失取值的具名表达

- 取值类型为 `UkCbValue`：`Present(f64)` 或 `Absent(理由)`。
- **不得**把缺失静默转 0；`UkCbValue::present()` 对缺失返回 `None`。
- 缺失理由只区分两类：`BlankInSource`（源行为空）与
  `ExplicitMarker`（源给出非数值标记）。清单未固定标记的字面含义，
  故本层**不解释**「cancelled」「provisional」之类语义。
- 非有限数值（NaN / 无穷）不是合法取值；`validate_observation` 会拒绝。
- 修订标识来自离线形态的 `revision` 列 / 字段；未提供时为 `None`，**不得伪造**。

## 9. 合成夹具声明

- `tests/fixtures/` 下的样本**全部是合成样本**：由特性 005 自拟，**不是**真实源数据，
  **不构成任何证据**，也不得被表述为「实测」「核验 PASS」或任何证据等级。
- JSON 夹具自带顶层 `_synthetic: true` 与非空 `_note`；CSV 夹具以
  `# _synthetic: true` 与 `# _note:` 前导行声明同一事实。
- 夹具的字段名与结构对齐 `specs/adapter/uk_cb.md` 声明的事实；
  **未**编造清单未提到的端点、字段或统计码。

## 10. 授权判定（fail-closed）

- `authorize` 在以下任一情形一律返回 `Denied`：证据缺失、覆盖范围不明、签署者不明、
  未获 Owner 签核、尚未生效、已过期。**不得**默认放行。
- 判定是**只读**结论：**不改变**名册的登记值，也**不**表示本库生产就绪。
- 本源当前**无**签核文件，故正常调用路径上的结果是 `Denied`；
  `Authorized` 仅在证据形状完整且落在有效期内时出现。
- `ensure_authorized` 把 `Denied` 映射为分类为 `AuthorizationDenied` 的类型化错误。

## 11. publication 与 PIT 资格

- `publication_semantics()` **恒为** `(Date, Inferred, NotEligible)`。
- `is_formal_pit_eligible()` 恒为 `false`（对应清单的 `is_formal_pit_eligible() == false` 口径）。
- **不得**补造 `00:00 UTC` / `21:00 UTC` 之类时刻把 `Date` 伪装成 `Instant`；
  也不得把 SONIA 的 `T+1` 节奏当作可得性证据层。
- 日后若接入官方 vintage 或经签批的发布日历，须先改清单与契约，**禁止静默升格**。

## 12. 依赖与零网络边界

- 依赖仅 `thiserror` / `serde` / `serde_json`；**禁止**任何 HTTP 客户端、异步运行时、
  `chrono` / `time` / `rand`，也**禁止**依赖任何其它 `bytechainx/*` crate。
- 源码中**没有**任何端点字面量、URL、凭据读取或代理配置；`http://` 与 `https://`
  不可出现在 `src/` 下的**任何** `.rs` 文件（含其内联测试）。需要 URL 字面量的
  负向用例一律放在 `tests/` 下，**不得**用「拆开 scheme 在运行期拼装」之类写法
  规避扫描 —— 那会让本条的可执行断言失去意义。
- 值对象**不实现**派生指标（净流动性、利差、Credit Impulse、z-score 等）；
  也不做单位换算 —— 单位以 `UkCbUnit` 原样保留，换算归下游 Normalize。
